Why it exists

Listening levels should not demand constant attention.

Films, streams, online video and adverts can arrive at very different levels. Quiet dialogue can be difficult to follow, then the next source or sudden peak can feel disproportionately loud.

Volume DAWg gives you measured control over those changes. It can level sustained differences, shape dynamics and catch sharp peaks while leaving you in charge of the listening profile. Results still depend on the source and your chosen settings.

01

Uneven sources

Reduce the jump between consistently quiet and loud material.

02

Abrupt peaks

Control short, sharp level changes without claiming perfect normalisation.

03

Hard-to-follow speech

Apply dedicated dialogue shaping when voices need more presence.

04

Manual volume riding

Keep useful control in one processing chain instead of chasing every change.

Verified capabilities

One control surface. Five clear layers.

The release-candidate build brings its main processing, tuning, routing and monitoring tools into a single Windows desktop interface.

01 / Control

Shape level changes

  • Dynamic LevellingTargets sustained listening level with defined boost and cut limits.
  • Smart CompressionControls dynamics with an adjustable strength and mode-aware character.
  • Ad Spike ControlResponds to sudden level jumps with sensitivity and recovery controls.

02 / Listening modes

Start from the material

  • FilmDeeper, smoother compression for wider film and TV dynamics.
  • OnlineLighter control with quicker recovery for everyday online video.
  • PunchFirmer, faster-acting control for sharper peaks.
  • Night ModeCoordinates levelling, compression, spike control and limiting for lower-volume listening.

03 / Tuning

Fine-tune the chain

  • Dialogue EnhancementAdjusts voice-focused processing independently.
  • Input TrimSets captured level before processing without changing Windows or browser volume.
  • 3-band EQProvides post-processing low shelf, mid gain and high shelf adjustment.
  • Final LimiterRemains active downstream to catch peaks before output.

04 / Routing

Choose the signal path

  • Source and destinationSelect captured audio and the playback endpoint for processed output.
  • Latency profilesChoose video-focused or audio-focused buffering without changing the sound processing.
  • Routing statusSee when processed audio is off, starting, active or needs setup.

05 / Monitoring

See what the processing is doing

  • Live levelsRead input and post-processing output level in real time.
  • Gain reductionTrack how much Smart Compression is reducing louder moments.
  • Signal analysisCompare original pre-DSP audio with processed post-limiter audio in the analyser.

Platform & processing

Built as a local Windows audio tool.

Volume DAWg is a Windows desktop application built with WPF on .NET 8. Its listening processing, routing and live metering run on the local machine.

Routing can use a separate or virtual playback endpoint between the source application and your speakers or headphones. Volume DAWg does not install an audio driver or mute the original source endpoint.
